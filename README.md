# Sarah Stitches

Site vitrine de couture et retouches. Construit avec HTML, CSS et JavaScript, prêt pour Netlify.

## Déploiement Netlify

- Repository : `Nokscoding/sarah`
- Branche de production : `main`
- Build command : aucune
- Publish directory : `.`

Les demandes de rendez-vous sont gérées par Netlify Forms une fois le site connecté et les formulaires activés. Les photos de démonstration doivent être remplacées par les réalisations authentiques avant lancement public.
