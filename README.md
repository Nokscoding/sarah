# Sarah Stitches

A responsive English-language couture and alterations website, built as a static Netlify site with semantic HTML, SEO tags, a gallery, services, FAQs, booking requests and an accessible responsive navigation.

**Production:** connect the `main` branch to the Netlify project `sarah-stitches`; publish directory `.` and no build command. Enable Netlify Forms and configure email notifications. The form is only active once deployed to Netlify.

Photos used in this GitHub version are externally hosted illustrative editorial stock and are **not** photographs of Sarah Stitches completed client work. Replace with the client-approved local images in the full website asset package before final launch. See `CONTENT_CHECKLIST.md`.

The final custom domain and business city/address have not been provided; SEO canonical URLs currently use `https://sarah-stitches.netlify.app`. Update before mapping a final domain.
